## 📖 Описание проекта

В рамках работы реализована архитектура для хранения и обработки информации о товарах и категориях. Проект включает в себя работу с JSON-данными, магические методы, итераторы и полное покрытие тестами.

### 🏗 Основные классы

#### 1. Класс `Product` (Товар)
Описывает товар в магазине. 
**Атрибуты:**
*   `name` — название товара.
*   `description` — описание товара.
*   `__price` — цена (приватный атрибут). Реализован через `@property` с проверкой (цена не может быть меньше 0, а при понижении цены запрашивается подтверждение).
*   `quantity` — количество на складе.

**Магические методы:**
*   `__str__` — выводит строку вида: `Название, X руб. Остаток: X шт.`
*   `__add__` — позволяет складывать два товара, возвращая общую стоимость (Цена1 × Количество1 + Цена2 × Количество2).

#### 2. Класс `Category` (Категория)
Описывает категорию товаров.
**Атрибуты:**
*   `name` — название категории.
*   `description` — описание категории.
*   `__prod` — приватный список товаров.
*   `products_count` и `category_count` — классовые переменные для автоматического подсчета созданных категорий и товаров.

**Магические методы и свойства:**
*   `__str__` — выводит строку вида: `Название категории, количество продуктов: X шт.` (считает общий остаток всех товаров в категории).
*   `products` — геттер, возвращающий строковое представление списка всех товаров категории.
*   `add_product()` — метод для добавления нового товара в категорию.

#### 3. Класс `CategoryIterator` (Итератор)
Вспомогательный класс для перебора товаров внутри конкретной категории. Реализует протокол итерации (`__iter__` и `__next__`), что позволяет использовать объект категории в цикле `for`.

## 🚀 Установка и запуск

Проект использует менеджер зависимостей [Poetry](https://python-poetry.org/).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vvoloshin77/e-commerce.git
   cd e-commerce
   ```

2. Установите зависимости:
   ```bash
   poetry install
   ```

3. Запустите демонстрационный скрипт:
   ```bash
   poetry run python src/main.py
   ```

## 🧪 Тестирование

В проекте написаны исчерпывающие тесты с использованием `pytest` (включая проверки строкового представления, сложения товаров, сеттеров и итератора).

Запуск тестов:
```bash
poetry run pytest
```

Запуск тестов с проверкой покрытия (Coverage):
```bash
poetry run pytest --cov=src --cov-report=term-missing
```
*Покрытие кода тестами составляет **100%**.*
