# 🛒 E-commerce Catalog «Каталог товаров»

## 📖 Описание проекта

Реализованы классы для хранения товаров и категорий, наследники для отдельных видов товаров, итератор по товарам категории и тесты на всю функциональность.

### 🏗 Основные классы

#### 1. `Product` (Товар)
Базовый класс товара.

**Атрибуты:**
* `name` — название;
* `description` — описание;
* `__price` — цена (приватный атрибут). Доступ через `@property`: нулевая или отрицательная цена не принимается, при понижении цены запрашивается подтверждение;
* `quantity` — количество на складе.

**Методы:**
* `__str__` — строка вида `Название, X руб. Остаток: X шт.`;
* `__add__` — общая стоимость двух товаров (цена × количество + цена × количество). Складывать можно только товары **одного класса**, иначе выбрасывается `TypeError`;
* `new_product()` — класс-метод: создаёт товар из словаря; если товар с таким названием уже есть в списке, складывает остатки и оставляет большую цену.

#### 2. Наследники `Product`

**`Smartphone` (Смартфон)** — дополнительно хранит:
* `efficiency` — производительность;
* `model` — модель;
* `memory` — объём встроенной памяти;
* `color` — цвет.

**`LawnGrass` (Трава газонная)** — дополнительно хранит:
* `country` — страна-производитель;
* `germination_period` — срок прорастания;
* `color` — цвет.

#### 3. `Category` (Категория)

**Атрибуты:**
* `name` — название;
* `description` — описание;
* `__prod` — приватный список товаров;
* `products_count`, `category_count` — атрибуты класса, считают все созданные товары и категории.

**Методы и свойства:**
* `__str__` — строка вида `Название, количество продуктов: X шт.` (суммарный остаток всех товаров);
* `add_product()` — добавляет товар в категорию. Принимает только объекты `Product` и его наследников, иначе выбрасывается `TypeError`;
* `products` — строка со всеми товарами категории;
* `product_list` — список товаров категории.

#### 4. `CategoryIterator` (Итератор)
Перебирает товары категории по одному. Реализует протокол итерации (`__iter__` и `__next__`), поэтому его можно использовать в цикле `for`.

#### 5. `BaseProduct` (Абстрактный базовый класс)
Родительский класс для всех продуктов (`ABC`). Описывает общий набор полей (`name`, `description`, `quantity`) и абстрактные методы, которые обязан реализовать каждый продукт: `__str__`, `__add__`, `new_product()` и свойство `price`. Создать объект `BaseProduct` напрямую нельзя.

#### 6. `PrintMixin` (Класс-миксин)
Подключён в цепочку наследования `Product`. При создании любого продукта, в том числе `Smartphone` и `LawnGrass`, печатает в консоль, от какого класса и с какими параметрами создан объект, например: `Product('Iphone 15', '512GB, Gray space', 210000.0, 8)`.

## 🚀 Установка и запуск

Проект использует менеджер зависимостей [Poetry](https://python-poetry.org/).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vvoloshin77/e-commerce.git
   cd e-commerce
   ```

2. Установите зависимости:
   ```bash
   poetry install
   ```

3. Запустите демонстрационный скрипт:
   ```bash
   poetry run python src/main.py
   ```

Также тесты проверяют вывод миксина при создании объекта и запрет на создание экземпляра абстрактного класса `BaseProduct`.

## 🧪 Тестирование

Тесты написаны на `pytest` и проверяют: создание объектов всех классов, сеттер цены, `new_product()`, строковое представление, сложение товаров (включая запрет на сложение товаров разных классов), проверку типа в `add_product()` и работу итератора.

Запуск тестов:
```bash
poetry run pytest
```

Запуск с отчётом о покрытии:
```bash
poetry run pytest --cov=src --cov-report=term-missing
```

HTML-отчёт о покрытии лежит в папке `htmlcov/`. Сгенерировать заново:
```bash
poetry run pytest --cov=src --cov-report=html
```

*Покрытие кода тестами составляет **100%**.*
